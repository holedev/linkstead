# A link code is permanent and the namespace is flat

A Mã link is never changed, never reused and never deleted, because the paper it was printed on is
still out there; a Link can only be switched off. The whole university shares one namespace
(`/cfp-2027`), first come first served, with a list of Mã dành riêng only a Quản trị hệ thống hands
out.

## Considered Options

- **A prefix per Đơn vị** (`/js/cfp-2027`) - rejected. It shows who owns a Link, but a code is
  permanent and a unit is not: faculties merge and are renamed, and the prefix would stay wrong on
  everything already printed. It would also make moving a Link between units change its address.
